# Laufzeit-Abhängigkeiten für uBuchhaltung.
#
# Der Kern (Webserver, DB, Rendering, Export) läuft mit der Python-
# Standardbibliothek (http.server, sqlite3, email, xml, ...). Externe
# Laufzeit-Abhängigkeiten:
#  * fontTools – bettet Liberation Sans als Untermenge in die erzeugten
#    PDF/A-3-Dokumente ein (export/pdfa.py). Pflicht, sonst keine PDF-Erzeugung.
#  * pdfplumber – PDF-Parsing von Kontoauszügen/Belegen im document_parser.py.
#    Fehlt es, läuft die App weiter – nur die PDF-Erkennung ist deaktiviert.
#
# Installation:  pip install -r requirements.txt
